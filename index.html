科研经历

1. 江淮前沿技术协同创新中心AI安全专业部 (2025.06 -- 至今)

本科实习生 | 导师：房江博士

[1] Stylistic Idiosyncrasies of Code Generated by Large Language Models(Accepted by CSCWD)

  • 项目描述: 针对大模型生成代码的普及带来审计安全问题，本研究结合监督对比学习与分类微调，通过构建多模型生成的高质量代码问答数据集，实现对不同 LLM 生成代码的精细识别与风格特征提取。实验结果显示模型可区分度显著，达 93.25% 准确率，对代码来源识别与审计具有重要价值。
  • 个人贡献：作为第一作者，负责多类代码生成数据集构建与清洗；基于 Meta-Llama-3-8B 的 LLM2Vec 构建编码器，完成监督对比学习与 M 类分类器训练；提取并量化代码风格特征，包括变量命名、注释使用等结构化模式，分析模型差异；绘制科研图表并可视化实验结果；完成论文撰写及实验附录整理。

[2] SAT4RIDS: Self-Supervised Learning Adversarial Training Framework for Robust Network Intrusion Detection System（Manuscript prepared）

  • 项目描述: 网络入侵检测中的异常流量识别长期面临对抗样本下鲁棒性不足的问题。本研究提出自监督 + 对抗训练结合的网络入侵检测框架，将对抗样本生成融入自监督学习。在CICIoT2022与ISCXVPN2016数据集上性能优异，原始样本准确率达到 99.86%，对抗样本准确率为 87.53%。
  • 个人贡献：作为第一作者，负责自监督特征学习框架设计，并引入对抗训练机制以提升模型鲁棒性；分析原始与对抗样本的性能差异并量化结果；完成论文撰写并绘制科研图表，呈现模型鲁棒性提升效果。

2. 北京邮电大学网络系统架构与融合重点实验室 (2025.11 -- 至今)

本科实习生 | 导师：夏海轮教授

[1] Signal-SGN++: Topology-Enhanced Time–Frequency Spiking Graph Network for Skeleton-Based Action Recognition(IEEE TNNLS, Under Review)

  • 项目描述: 针对资源受限设备下骨骼动作识别的精度与能耗问题，本研究结合 1D 脉冲图卷积与频率脉冲卷积，同时建模骨骼关节的空间拓扑、时间动态和频域特征。基于 NTU-RGB+D/NTU120/NW-UCLA 数据集验证，Top-1 精度较基线提升 8-15%，能耗较传统 GCN 下降 30%，FLOPs 降低 77%-93%。
  • 个人贡献：参与 MWTF 模块（多尺度小波变换融合）和 TSSA 模块（拓扑转换自注意力机制）的技术设计与实现；负责科研图表绘制与方法可视化，将复杂网络结构、实验流程及结果直观呈现。

4. 中国科学院自动化研究所 – 复杂系统认知与决策重点实验室 (2026.01 -- 至今)

本科实习生 | 导师：黄凯奇教授

研究方向：大语言模型驱动的人机博弈代理（LLM-based Agents for Human-Machine Gaming）

主要工作与成果：

  • 自演化博弈代理机制研究
    • 基于大语言模型构建自演化代理框架（参考 Richelieu）。
    • 研究自对弈（Self-Play）方法，让代理在无需人类标注数据的情况下，通过不断自我训练在Diplomacy等复杂博弈中实现：
      • 超越人类水平的策略规划
      • 动态谈判能力与多方对抗
  • 复杂记忆系统架构设计
    • 调研多种 Agent 长期记忆管理方案，重点探索以下方法：
      • Zettelkasten（卢曼卡片盒）思想：基于动态索引与链接构建记忆网络（参考 A-Mem）
      • 艾宾浩斯遗忘曲线 + 图数据库：结合 MemoryBank 和 Mem0，优化记忆更新机制
    • 目标：确保 Agent 在长周期博弈中保持上下文一致性，提高决策连贯性
